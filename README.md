🔐 Project Lock — Simulador de Controle de Acesso
O Project Lock é um projeto de estudos desenvolvido em Python com o propósito exclusivo de exercitar e consolidar conceitos de lógica de programação, controle de fluxo e manipulação de estados.
A proposta do projeto é simular a lógica por trás de um sistema de fechadura eletrônica controlada remotamente, voltado para gerenciar o fluxo de entrada e saída em ambientes comerciais — como banheiros de estabelecimentos, escritórios e salas de reunião.

🎯 Objetivo do Estudo
O foco central deste repositório foi colocar em prática fundamentos essenciais da linguagem Python através de um problema do mundo real, abordando:
Gerenciamento de Estado: Representação e controle dos estados de travamento e liberação da porta.
Regras de Negócio e Lógica: Validação de solicitações de acesso e prevenção de acionamentos inválidos.
Estrutura de Código: Organização de rotinas, funções e rotulagem de eventos (logs de acionamento) em ambiente simulado.

🤖 Uso de IA como Copiloto
Durante a elaboração da lógica e escrita do código, uma Inteligência Artificial foi utilizada como copiloto. O suporte da IA foi focado em:
Esclarecer dúvidas pontuais sobre a sintaxe e recursos do Python.
Discutir e comparar diferentes abordagens para a resolução da lógica do simulador.
Auxiliar na depuração de cenários e validação de boas práticas de código.
🛠️ Tecnologias e Escopo
Linguagem: Python 3.x
Natureza do Projeto: Simulador estritamente lógico de software (execução via console/terminal).
Status: Concluído / Projeto de aprendizado finalizado.
